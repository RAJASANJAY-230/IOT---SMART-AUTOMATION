# IOT---SMART-AUTOMATION
IoT-Based Home Automation Using NodeMCU ESP8266 and Blynk

This project is an IoT-based home automation system developed using the NodeMCU ESP8266, Blynk IoT platform, and a 4-channel relay module. It allows users to remotely control multiple household appliances through a smartphone using a Wi-Fi connection.

The system receives commands from the Blynk mobile application and controls the connected appliances through relay modules. Manual switches can also be used for local control, providing an additional way to operate the appliances.

Technologies Used
C/C++
Arduino IDE
NodeMCU ESP8266
Blynk IoT
Wi-Fi
4-Channel Relay Module
Features
📱 Remote appliance control through Blynk
🌐 Wi-Fi-based IoT connectivity
💡 Control of multiple appliances
🔌 Relay-based switching
🔘 Manual switch control
📊 Real-time appliance status through Blynk
Objective

The main objective of this project is to develop a simple, low-cost, and IoT-enabled home automation system that makes controlling household appliances more convenient and accessible.
